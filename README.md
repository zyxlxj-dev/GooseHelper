# 抓大鹅 AI 辅助器（Android 工程起始版）

目标设备：小米 Android 13。模式：只识别、只标记，不自动点击。

## 当前包含
- Android 原生 Kotlin 工程
- MediaProjection 屏幕捕获授权流程
- 前台服务
- 透明、不可触摸的悬浮标记层
- 标记坐标接口 `MarkerOverlay.setMarkers(...)`

## 重要限制
此工程**不是已编译 APK**。当前容器没有 Android SDK/Gradle 构建环境，且尚未取得实际「抓大鹅」截图，因此不能诚实地声称已生成可安装 APK或完成道具识别。`CaptureService.kt` 中的 TODO 是接入游戏专用识别器的位置；在完成识别器前，应用只搭好捕获和叠加框架，不会自动识别道具。

## 下一步需要
请提供一张游戏进行中的完整屏幕截图（尽量包含全部道具，保持原始分辨率，不要裁剪）。最好再提供一张道具位置变化后的截图。用于确认道具形状、遮挡、缩放、排列方式，再实现检测与相似道具聚类。

## 构建
使用 Android Studio 打开此文件夹，等待 Gradle Sync，然后 Build > Build APK(s)。建议先在测试设备上验证屏幕捕获与悬浮窗权限。
